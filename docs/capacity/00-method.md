# 용량 산정 방법: 로컬 측정에서 DAU 1억까지

DAU 1억은 가정으로 시작하지 않습니다. 로컬에서 부품 하나가 감당하는 양(단위 용량)을 먼저 재고, 그 값을 환산해 필요한 규모를 계산합니다. 로컬에서 증명할 수 없는 부분은 글로벌 설계 문서(`03-global-topology.md`)로 분리합니다.

```
1. 로컬 예산 확정
2. 부품별 단위 용량 측정 (SLO를 지키는 최대치)
3. 레플리카 1 → 2 → 3 으로 선형성 확인, 꺾이는 지점과 원인 기록
4. DAU 1억 부하 모델 작성
5. 환산: 필요 대수 = 피크 부하 / (단위 용량 × 목표 사용률)
6. 로컬에서 증명 못 한 것 → 글로벌 설계
```

## 1. 로컬 예산

| 자원 | 전체 | 이 프로젝트 할당 |
|---|---|---|
| CPU | M2 Pro 12코어 | Docker 8코어, 부하 발생기 2코어, 나머지 OS |
| 메모리 | 16GB | Docker 10GB |
| 디스크 여유 | 152GB | 테스트 영상 원본과 트랜스코딩본 합계 50GB 상한 |

측정 결과는 모두 이 조건과 함께 기록합니다. 조건 없는 숫자는 환산에 쓰지 않습니다.

## 2. 측정할 단위 용량

| 부품 | 단위 용량 정의 | 연결 NFR | 측정 도구 |
|---|---|---|---|
| API 인스턴스 | 코어당, p99 < 200ms를 지키는 최대 QPS (캐시 히트 / 미스 따로) | NFR-4 | k6 |
| Redis | 초당 INCR, GET 처리량 | NFR-4, FR-5 | redis-benchmark, k6 |
| DB | 초당 쓰기 TPS, 인덱스 조회 p99 | FR-4 | k6, 슬로 쿼리 로그 |
| 트랜스코딩 워커 | 코어당 처리 속도 (영상 길이 초 / 실제 소요 초), 해상도별 | FR-2 | 워커 자체 지표 |
| 객체 스토리지 (MinIO) | 업로드 쓰기 MB/s, 세그먼트 읽기 MB/s | FR-1, FR-3 | k6, mc |
| 조회수 집계기 | 초당 이벤트 처리량, 반영 지연 | FR-5, NFR-6 | 자체 지표 |

## 3. 선형성 확인

API와 워커를 1, 2, 3개로 늘리며 처리량을 잽니다. 목적은 세 가지입니다.

- 무상태 설계가 실제로 수평 확장되는지 증명 (NFR-7)
- 꺾이는 지점을 찾아 공유 자원(DB 커넥션, Redis, 디스크 I/O) 중 무엇이 병목인지 기록
- 그 병목이 DAU 1억에서 어떤 설계로 풀리는지 연결 (샤딩, 캐시, 복제)

로컬에서 꺾이는 원인이 "같은 머신이라서"인지 "설계 때문"인지 구분해서 적습니다. 앞의 것은 환산에서 제외하고, 뒤의 것은 ADR 후보가 됩니다.

## 4. DAU 1억 부하 모델

| 가정 | 값 | 근거 |
|---|---|---|
| DAU | 1억 | 주어진 조건 |
| 1인당 하루 시청 | 5편 | |
| 평균 시청 시간 | 5분 | |
| 평균 비트레이트 | 2.5Mbps | 720p 기준 |
| 하루 업로드 | 50만 편 | 시청의 약 0.1% |
| 평균 원본 크기 | 300MB | |
| 피크 배수 | 평균의 3배 | |

| 파생 값 | 계산 | 결과 |
|---|---|---|
| 재생 시작 요청 평균 QPS | 1억 × 5 / 86,400 | 약 5,800 |
| 재생 시작 요청 피크 QPS | × 3 | 약 17,000 |
| 세그먼트 요청 피크 QPS | 피크 동시 시청자 × (1 / 세그먼트 길이) | ADR-0007 결정 후 계산 |
| 평균 이그레스 | 5억 × 300초 × 2.5Mbps / 86,400 | 약 4.3Tbps |
| 원본 저장 증가량 | 50만 × 300MB | 하루 약 150TB |
| 트랜스코딩 부하 | 50만 × 평균 영상 길이 × 해상도 수 | 워커 단위 용량으로 대수 환산 |

## 5. 환산식

```
필요 대수 = 피크 부하 / (단위 용량 × 목표 사용률)
```

- 목표 사용률은 0.5~0.6으로 잡습니다. 한 AZ가 죽어도 남은 용량으로 버티기 위한 여유입니다.
- 로컬 코어와 서버 코어의 성능 차이는 코어당 수치로 정규화하고, 보정 계수를 따로 적습니다.
- 이그레스처럼 로컬에서 의미 있게 잴 수 없는 값은 환산하지 않고 CDN 캐시 히트율 가정으로 다룹니다.
