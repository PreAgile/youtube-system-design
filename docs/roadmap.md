# 주차별 진행 계획

멘토 세션은 주 1회입니다. 매주 세션 전에 그 주 산출물과 ADR을 Proposed 상태로 올리고, 세션에서 받은 피드백을 반영해 결정한 뒤 Accepted로 바꿉니다.

W2의 작업 범위와 발표 준비는 [W2 멘토 세션 준비 가이드](interview/01-mentor-session-guide.md)를 따릅니다. 준비 기준은 45분 보드 모의 인터뷰이며, 실제 시간은 멘토와 합의합니다. 10분 요약은 피드백 정리 또는 시간이 줄었을 때의 대체안입니다.

| 주차 | 산출물 | 결정할 ADR | 세션에서 발표할 것 |
|---|---|---|---|
| W1 | 범위, FR/NFR, ADR 틀, 언어 특성 비교 | 0001, 0002 | 범위를 이렇게 자른 이유, NFR 숫자, 언어 특성으로 본 선택 근거 |
| W2 | 부하 모델, 최소 API 명세, 데이터 모델, Excalidraw HLD와 핵심 시퀀스 | 0003 ~ 0007 (0003·0004는 먼저 비교 메모, 정식 ADR은 템플릿에 따라 후속 작성) | 코드 없이 45분 모의 인터뷰. 업로드·변환·재생·조회수 경로와 CDN·캐시·확장 조건 개요. 상세 결정과 검증은 W6~W8 |
| W3 | repo 뼈대, docker-compose, 메타데이터 API, 첫 로컬 측정 | | API 단위 용량 측정 결과 |
| W4 | 업로드 (Presigned Multipart, 완료 처리 멱등) | | D1 딥다이브, 업로드 중단과 재개 데모 |
| W5 | 트랜스코딩 워커, 상태 머신, Outbox | 0010 | D2 딥다이브, 인코딩 중 워커 강제 종료 후 복구 데모 |
| W6 | HLS 재생, Signed URL, 캐시 | 0008 | D3, D4 딥다이브 |
| W7 | 조회수 집계 | 0009 | D5 딥다이브, 처리량과 반영 지연 측정 |
| W8 | 선형성 측정, DAU 1억 환산, 글로벌 설계 | 0011, 0012 | 로컬 수치에서 1억까지 이어지는 계산 |
| W9 | 꼬리질문 대비 문서, 발표 리허설 | | 최종 모의 인터뷰 (45분 설계 + 10분 데모) |

정지선은 W9입니다. Stretch 기능(좋아요, 구독 피드, 검색)은 W9까지 끝난 뒤에만 손댑니다.

## 매주 반복하는 흐름

1. 세션 전: 구현, 측정, ADR 초안 (Proposed)
2. 세션: 발표, 질문 받기
3. 세션 후: 답하지 못한 질문을 `docs/interview/qa-bank.md`에 기록, ADR 결정 (Accepted)
