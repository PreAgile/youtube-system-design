## 3. 사용자 제안과 검토

## 4. 결정과 이유

Proposed라면 아직 비교 중이라고 표시한다. Accepted라면 사용자가 선택한 결론과 이유를 적는다. 말하지 않은 경험이나 측정값을 만들지 않는다.

조건·결과·한계를 연결한다. 검증 전이면 실험 계획을 적고 미검증이라고 표시한다.
